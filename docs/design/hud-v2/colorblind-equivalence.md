# Equivalência dos perfis de daltonismo

A prancha muda quando muda uma cor semântica. Uma tela inteiramente neutra pode ser idêntica nos dois perfis: os ícones, palavras e formas já comunicam o estado. Não recolorir a pintura ou o personagem só para produzir outro hash.

`explore-risk` usa painel, texto e foco neutros; a perda de metade é escrita. Não há vermelho de perigo nesse diálogo. `station`, `title` e `combat` também usam sinais neutros nas vistas fixas. Nas miras, os realces semânticos foram capturados novamente pela Godot e mudam para laranja; na vida ferida do relatório há a troca vermelho/laranja. Os PNG abaixo são propostas solicitadas na #58; os PNG brutos de captura permanecem fora do Git.

# Narrativa

A base da história do After Humans, trazida da referência Unreal (`Docs/Design`) em 24/10/2026. A partir daqui, estas
cópias são as que valem para o jogo da Godot.

- [lore.md](lore.md): a Bíblia de Lore (a Peste, os animais, as facções, o VIGIA, os humanos).
- [narrative-design.md](narrative-design.md): como contar (expedições, escolhas, eventos, a escada de revelações, o tom e a
  regra de consistência).
- [bento-nick-arc.md](bento-nick-arc.md): o arco dos fundadores.
- [corridor-progression.md](corridor-progression.md): a progressão dos corredores e das fases.

Todo texto de tela, evento, nome, lugar, item, inimigo e descrição de fase passa pela regra de consistência
(`narrative-design.md`, seção 14) antes de entrar no jogo.
